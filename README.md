# We Build — The Website Collection

Static website featuring 20 construction trade templates, distinct sample photography, a cinematic header and the charcoal/amber main palette.

## Run
Open index.html in a browser. No build step or dependencies are required.

## GitHub Pages
Upload these files to the root of a GitHub repository. In repository Settings > Pages, select Deploy from a branch and choose the main branch, root folder. GitHub provides the shareable website URL after deployment.

The site uses relative asset paths and hash routes, compatible with a GitHub Pages project site.

The main contact form opens a prepared email for the visitor to send; it does not submit to a backend. Trade enquiry forms download a sample brief. Photos and projects are illustrative examples, not real client work. See ASSETS.md and sample-image-sources.json for photography sources.
